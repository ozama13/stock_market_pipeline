# 📈 Real-Time Stock Market Data Pipeline  

## 🚀 Overview  
This project builds a **real-time stock market data pipeline** that fetches stock prices from an API, processes and stores the data in a cloud database, and visualizes trends.  

✅ **Real-time Data Ingestion** – Fetch stock prices from Yahoo Finance API  
✅ **Streaming Data Processing** – Kafka + Apache Spark  
✅ **Cloud Database** – PostgreSQL (AWS RDS) / Snowflake  
✅ **Orchestration** – Apache Airflow for scheduling ETL jobs  
✅ **Visualization** – Tableau or Streamlit Dashboard  

---

## 🔧 Tech Stack  
- **Data Source**: Yahoo Finance API / Alpha Vantage  
- **Streaming Framework**: Apache Kafka / AWS Kinesis  
- **Processing & Transformation**: Apache Spark / Pandas  
- **Database**: PostgreSQL (AWS RDS) / Snowflake / BigQuery  
- **Orchestration**: Apache Airflow  
- **Visualization**: Tableau / Streamlit
